# Núcleo de Gobernanza para Agentes de IA

Los documentos contenidos en este directorio definen las reglas fundamentales que rigen el comportamiento de cualquier agente de inteligencia artificial que participe en el desarrollo de este proyecto.

Estas reglas tienen prioridad sobre cualquier otra guía del proyecto.

Todos los agentes deberán leer este directorio antes de consultar las reglas específicas de arquitectura, tecnologías, seguridad o flujos de trabajo.

## Objetivos

- Mantener un comportamiento consistente entre diferentes agentes.
- Priorizar la seguridad y la estabilidad del sistema.
- Reducir modificaciones innecesarias.
- Facilitar el mantenimiento del código.
- Favorecer la velocidad de desarrollo sin sacrificar calidad.
