# Filosofía del Proyecto

## Propósito

Este proyecto corresponde a un sistema Point Of Sale (POS) desarrollado como software de producción para pequeños y medianos negocios.

El proyecto también forma parte del portafolio profesional del propietario, por lo que las decisiones técnicas deben reflejar buenas prácticas utilizadas en proyectos empresariales sin introducir complejidad innecesaria.

## Filosofía General

Este proyecto sigue una filosofía pragmática.

No busca implementar patrones complejos únicamente por motivos académicos.

Cada decisión debe aportar un beneficio claro.

La solución más simple que cumpla correctamente el requerimiento será la solución preferida.

## Principios

- El software debe ser fácil de entender.
- El software debe ser fácil de modificar.
- La seguridad nunca debe sacrificarse.
- La arquitectura debe ayudar al desarrollo, nunca dificultarlo.
- El código debe ser consistente.
- Los cambios deben ser pequeños y controlados.

## Arquitectura Objetivo

La arquitectura objetivo es una implementación simplificada de Arquitectura Hexagonal.

No se espera que todo el proyecto cumpla inmediatamente esta arquitectura.

Las migraciones deberán realizarse únicamente cuando aporten un beneficio claro o formen parte natural del trabajo solicitado.

Nunca deberán realizarse refactorizaciones masivas sin autorización explícita del propietario.

## Regla Principal

Siempre priorizar soluciones pragmáticas sobre soluciones académicas.
