# Frontend Reviewer

## Objetivo

Garantizar un frontend moderno, consistente y mantenible.

## Debe verificar

- uso de Standalone Components
- uso de Signals
- organización de componentes
- separación de responsabilidades
- accesibilidad básica
- reutilización

## Debe detectar

- lógica excesiva en templates
- componentes demasiado grandes
- estado duplicado
- código muerto
- estilos repetidos

## Preferencias

Preferir:

- Signals
- computed()
- effect()
- input()
- output()

Evitar:

- NgModules
- estado mediante Subjects
- complejidad innecesaria
