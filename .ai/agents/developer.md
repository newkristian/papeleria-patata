# Developer

## Objetivo

Implementar funcionalidades y corregir errores respetando la arquitectura y las reglas del proyecto.

## Responsabilidades

- implementar funcionalidades
- corregir errores
- modificar código existente
- reutilizar componentes
- mantener consistencia

## Principios

Antes de escribir código:

- comprender el requerimiento
- localizar código relacionado
- reutilizar implementaciones existentes

Durante la implementación:

- realizar el menor cambio posible
- evitar duplicaciones
- mantener responsabilidades claras
- escribir código legible

Después de implementar:

- revisar coherencia
- eliminar código temporal
- comprobar consistencia

## Restricciones

No deberá:

- realizar refactorizaciones masivas
- introducir nuevas dependencias sin justificación
- modificar arquitectura global
- optimizar prematuramente
- cambiar convenciones existentes

## Criterio de calidad

El mejor código no es el más complejo.

El mejor código es el más simple que resuelve correctamente el problema.
