# Búsqueda de productos en el POS

**Estado:** Aprobado  
**Última revisión:** 28 de agosto de 2026

## Objetivo

Buscar productos activos por nombre o código de barras y agregarlos rápidamente al
carrito.

## Dependencias verificadas

- El backend dispone de búsqueda paginada y consulta por código de barras.

## Implementación verificada

No existe servicio ni componente frontend para esta funcionalidad.

## Criterios de aceptación

- Maneja carga, resultados vacíos, errores y productos sin stock conocido.
